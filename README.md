# تطبيق MyGram 

تطبيق ويب مبني بإطار العمل **Laravel** يحاكي المنصة الشهيرة **Instagram** من حيث الوظائف الأساسية، مع التركيز على رفع الصور ومشاركتها بين المستخدمين.

> 🚫 لا يدعم المشروع حالياً رفع الفيديوهات أو القصص، بل يقتصر فقط على الصور.

## الخصائص الأساسية
- تسجيل مستخدمين جدد وتسجيل الدخول.
- رفع الصور مع وصف توضيحي.
- عرض منشورات المستخدمين الآخرين.
- متابعة وإلغاء متابعة المستخدمين.
- صفحة ملف شخصي لكل مستخدم.
- الإعجاب بالمنشورات والتعليقات عليها.
- المشروع يأتي أساسا باللغة العربية وهو يدعم اللغة الإنجليزية عند تعديل بيانات الصفحة الشخصية للمستخدم

---

## المتطلبات

- PHP 
- Composer
- MySQL قاعدة بيانات
- Laragon يفضل استخدامه من أجل سهولة إعداد كل ما سبق
- Laravel
- Node.js و npm (من أجل  ملفات الواجهة)

---

## خطوات التثبيت والتشغيل

1. ** تحميل المشروع ووضعه في المجلد المناسب لبيئة تشغيل مشاريع php لديك على الجهاز ويفضل استخدام laragon ووضع المشروع في المكان المناسب في مجلد laragon طبقا للتعليمات المتعلقة ب laragon**
2. ** تثبيت الاعتماديات الخاصة بالمشروع **
- composer install  
- npm install
4. ** تشغيل السيرفر المحلي ويفضل laragon ثم تشغيل قاعدة البيانات من خلاله وإنشاء قاعدة باسم mygram **
5. ** تشغيل التهجير لإنشاء الجداول من خلال الأمر php artisan migrate **
6. ** تشغيل Vite لتجميع الواجهة من خلال الأمر npm run dev **
7. تشغيل التطبيق في المتصفح من خلال الأمر php artisan serve ثم الضغط على الرابط الذي يظهر لديك في الترمنال  **
